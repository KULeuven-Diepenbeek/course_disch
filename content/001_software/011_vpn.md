### OpenVPN
<img src="../../images/001/logo_openvpn.png" style="float: right; margin: 0px 10px"/>

De (open source) software die gebruikt wordt voor de VPN verbinding is **OpenVPN**. Deze software kan je downloaden vanop hun [website](https://openvpn.net/client-connect-vpn-for-windows/). Met behulp van de files die jullie **persoonlijk** ter beschikking krijgen, kan OpenVPN een connectie maken de server **roger**. Samen met de configuratie van de verbinding ontvangen jullie ook de nodige sleutels en certificaten.

**Dénk er aan dat je telkens deze verbinding maakt voordat je met de services probeert te verbinden.**



<hr/>

### Remote access

<img src="../../images/001/logo_mobaxterm.png" style="float: right; margin: 0px 10px"/>

Door gebruik te maken van een VPN, wordt er toegang verschaft tot het netwerk. Het volgende dat nodig is, is een tool (of een set of tools) die bepaalde functionaliteiten biedt. De tool **MobaXterm** is gratis beschikbaar en biedt services zoals o.a. SSH en FTP functionaliteit en een X-window function. Download (de home edition) van [https://mobaxterm.mobatek.net/](https://mobaxterm.mobatek.net/download.html)

Wanneer de software geïnstalleerd is, dient er een **nieuwe sessie** gemaakt te worden. Het IP-adres van de server is **193.190.58.21** en de poortnummer is **2222**. Als advanced setting kan je de **X11-Forwarding** aanzetten.

![Moba 1](/images/001/moba_1.png)

Vervolgens, op het *Bookmark settings* tab-blad, kan de sessie een naam gegeven worden. Ter illustratie kan de server **Roger** genoemd worden.

![Moba 1](/images/001/moba_2.png)

Tenslotte dient de login en het wachtwoord ingevoerd te worden. Eens je verbonden ben, kan je, aan de linkerkant van het MobaXterm scherm, door het bestandssysteem gebladerd worden.

![Moba 1](/images/001/moba_3.png)

### Tight VNC

<img src="../../images/001/logo_tightvnc.png" style="float: right; margin: 0px 10px"/>

De derde tool die nodig is, is een VNC-viewer. **VNC (Virutal Network Computing)** is een grafisch tool om een Desktop over te nemen. Op de server(s) in het virtuele netwerk kan een VNC-server gestart worden. Hierop kan er dan verbonden worden met een VNC-client. Een optie voor de VNC client is TightVNC. Dit kan gedownload worden op [https://www.tightvnc.com/](https://www.tightvnc.com/download.php).
